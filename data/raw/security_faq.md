# CloudSync Security FAQ

## Data Encryption

All files are encrypted in transit using TLS 1.3 and at rest using the AES-256
algorithm. Encryption keys are managed by an internal Key Management System (KMS) and
rotated automatically every 12 months.

## GDPR Compliance

CloudSync processes data in compliance with GDPR. Data belonging to customers in the
European Union is stored exclusively in data centers located within the EU (Frankfurt,
Amsterdam). Users can request an export or deletion of their data from the
Settings > Privacy > Data Management panel.

## Certifications and Audits

CloudSync holds a SOC 2 Type II certification, renewed annually by an independent
auditor. The audit report is available upon request for Enterprise plan customers after
signing an NDA.

## Reporting Security Vulnerabilities

Security vulnerability reports should be sent to security@cloudsync.example.com.
CloudSync runs a bug bounty program with rewards ranging from $100 to $2,500 depending
on the severity of the reported issue.
